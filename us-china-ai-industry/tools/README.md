# evidence-gate.js — 证据门禁最小原型

来源：[../modules/C4-personal-convergence.md](../modules/C4-personal-convergence.md) C4.2 第一条 / 遗留待办 3。
定位：把本仓库的固定流程纪律做成**可执行的 gate 检查**（拦截复核提示，不是自动定罪——判定权在人/agent，B4 原则的工具化版本）。纯本地、零依赖、未装入任何全局配置目录。

## 用法

```bash
node tools/evidence-gate.js                # 默认扫描 modules/*.md + final-report.md + outline.md
node tools/evidence-gate.js <文件或目录>     # 指定目标（目录递归 .md）
node tools/evidence-gate.js --selftest     # 内置判例自测（期望值=ground truth）
```

退出码：有 ERROR → 1；仅 WARN 或全净 → 0。
若 shell 里没有 `node`（本机 Git Bash 即如此），可在任意 Node 环境 `require` 本文件后调 `checkLines(label, text)`，或让 agent 经 node-repl 执行。

## 规则集（v1）

| 规则 | 级别 | 判据 |
|------|------|------|
| R1 口径注 | ERROR | 行含 "47.5%" 且无任何口径限定词（存疑/待核/降级/核实/验证/未见可靠/无法独立/口径）——裸引即违例；元陈述句放行 |
| R2 必然叙事 | ERROR | 行含"必然胜利/崩溃/取代/赢/输"且非纪律陈述（GUARD：禁用/证伪/目的论/✓ 等放行） |
| R3 ★级采数 | WARN | 行含孤★（非★★/★★★）+ 具体带单位数字 + 无"只采方向/不采信/待核"隔离词 |
| R4 引用缺级 | WARN | 正文行内引用 http(s) URL 但同行无 ★ 证据级标注 |
| R5 KPI来源闸 | WARN | OEE/良率/检出率/提效/降本/渗透率 + 量化增幅，同行无"宣传/厂商/口径/核实/原文"隔离词 |
| R6 核对节 | WARN | modules/A*/B*/C* 文件缺"数据核对记录"或"遗留待办"节 |

GUARD 隔离词表：不采/零采/待核/存疑/口径/方向/氛围/降级/证伪/禁用/禁止/纪律/宣传/厂商/原文/隔离/防/警惕/核实/目的论/✓/未见可靠/无法独立。

## 测试结果（2026-10-03，node-repl 实跑）

1. **自测判例集：12/12 PASS**。含三组对照：违例必命中（47.5% 裸引、必然崩溃论、★源采数、KPI 宣传裸引、URL 无级）与合规必放行（口径存疑引用、"无法独立验证口径，降级"元陈述、纪律陈述句、★源只采方向、已隔离 KPI、URL 带级、无★纯日期行）。
2. **本仓库全量扫描（19 文件）**：ERROR 0、WARN 12。首轮曾有 4 个 ERROR 误报（A1/A5/B5/outline 的"核查/限制句"），据此加入元陈述放行词后清零——**误报修复过程本身即判例集扩充**。12 个 WARN 逐条抽检均为"★+数字"或"URL 行内引用"待复核提示，符合设计（如 B1 L55"★ 源，待 US Census 升级"用的是"待 X 升级"句式，不在隔离词表——保留为提示，宁滥勿漏）。R6 如实报出 B4 无核对节（方法论文件，属预期）。
3. **finance_expert 域可迁移性（19 文件）**：ERROR 0、WARN 18，**18 条全部是 R4**。结论：R1/R2/R3/R5 跨域零误报（该库用 ✅/⚠️/canary 标注体系，★ 规则自然不触发），但 **R4 预设了"引用必须带 ★ 级"这一本仓库约定**，对 finance_expert 是系统性误报——门禁规则是**域配置文件**而非普适真理。

## 已知边界与下一步

- 行级启发式：跨行限定词（脚注、表头列名）会漏判/误判，故 R3/R5 只到 WARN。
- 域适配：下一步加 `--config`（隔离词表、引用标注体系 ★ vs ✅、目录模式）；finance_expert 试跑只需关 R4 或换标注判据（C4.2 原计划"先 finance 域"由此改为"两域各跑一轮"完成）。
